# GitFaye Plugins
A collection of GitFaye plugins. These plugins are for scanners, checkers and more.

# ⚙️ Installations
## Github
```
git clone https://github.com/firstdecree/gitfaye-plugins
```

## NpmJS
```
npm install ky dns
```

## PNPM
```
pnpm install ky dns
```

# 🚀 Usage
The plugins are automatically downloaded, updated and used on GitFaye (Web) and GitFaye CLI.
